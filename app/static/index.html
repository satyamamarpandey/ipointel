Predictions that cannot be rewritten later.

Before listing, the system permanently records a snapshot. After listing, the outcome is attached separately — never merged back into the original.

Recorded before listing

  • Timestamp
  • Model version
  • Score
  • Probability
  • Recommendation
  • Source snapshot

Attached after listing

  • Actual listing return
  • 1 / 6 / 12-month return
  • Outcome vs. prediction
The prediction stays frozen. The result gets added later.
